# SAAD DEVELOPER — Portfolio

A responsive, single-page developer portfolio built with React, Vite, Tailwind CSS, Framer Motion, and Lucide React. Project artwork is made with CSS and SVG, so the page does not depend on large stock photos.

## Run locally

Use Node.js 20.19+ and npm, then run:

```sh
npm install
npm run dev
```

Create and preview an optimized build with `npm run build` and `npm run preview`.

## Personalize before publishing

- Replace the disabled email and WhatsApp placeholders with Saad’s real contact details.
- Connect the form to an email service or backend route. Until then, valid submissions are checked in the browser and clearly reported as unsent.
- Add real project deployment and repository URLs. The displayed work is explicitly labeled as personal concept work, and its project actions remain disabled until URLs are supplied.
- Add actual GitHub and LinkedIn profile URLs in the footer.
- Replace or expand the meta description and Open Graph cover if a custom production domain is added.

The theme switch remembers a visitor’s preference when browser storage is available. Animations respect the operating system’s reduced-motion setting.
